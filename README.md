# Ispdock

The ISPDock website (ispdock.com): plain static files, no build step.

- `index.html`, `site.css`, `site.js`, `favicon.svg`
- Preview locally: `python3 -m http.server 3010` in this folder, then open http://localhost:3010
- "Book a demo" and Contact links: the `CONTACT` constant at the top of `site.js`
- Prices must match the platform's pricing sheet; change both together.
